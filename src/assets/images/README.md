## Куда добавлять картинки

Кладите изображения сюда:

- `src/assets/images/`

### Как подключать в компонентах

Пример:

```js
import heroImg from "../../assets/images/hero.jpg";
```

Далее используйте `heroImg` в `src` или в стилях через inline background.

### Рекомендации

- Старайтесь использовать `.jpg`/`.webp`
- Оптимальный размер по ширине: ~\(1600–2400\)px для hero, ~\(1200–1600\)px для карточек
